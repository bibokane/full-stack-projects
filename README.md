# Full-Stack-Projekte Portfolio

Eine Sammlung von Full-Stack-Webanwendungen, entwickelt mit Spring Boot, React, Angular und modernen Web-Technologien.

## 📋 Projekte

### 🎯 Job Portal
**Spring Boot MVC | Thymeleaf | MySQL**  
Jobbörse mit serverseitigem Rendering für Jobsuchende und Recruiter. Features: Benutzerverwaltung, Jobsuche, Spring Security.

**Stack:** Spring Boot 3.5.3, Java 21, Thymeleaf, Spring Security, MySQL  
**→** [Details](jobportal/README.md)

### 📚 Library Management System
**React | Spring Boot | MySQL**  
Bibliotheksverwaltung mit React SPA und RESTful API. Features: Buchverwaltung, OAuth2/Auth0, Ausleihsystem, Review-System.

**Stack:** React 19.1.0, TypeScript, Spring Boot 3.5.3, OAuth2, MySQL  
**→** [Details](library-app/README.md)

### 🏆 Turnier App
**Angular | Spring Boot | H2**  
Turnierverwaltung für 16 Mannschaften mit Gruppenphase und K.O.-System. Features: Automatische Tabellenberechnung, moderne UI.

**Stack:** Angular 17, TypeScript, Spring Boot 3.2.0, Spring Data JPA, H2  
**→** [Details](turnier-app/README.md)

## 🚀 Quick Start

Jedes Projekt enthält eine eigene README mit detaillierten Installationsanleitungen.

### Voraussetzungen
- **Java** 17+ (21 empfohlen)
- **Node.js** 16+ und npm
- **Maven** 3.6+
- **MySQL** 8.0+ (für Job Portal und Library App)

## 🔧 Technologie-Stack

| Kategorie | Technologien |
|-----------|-------------|
| **Backend** | Spring Boot 3.x, Java 17/21, Spring Data JPA, Spring Security |
| **Frontend** | React 19, Angular 17, TypeScript, Bootstrap |
| **Datenbank** | MySQL 8.0, H2 (In-Memory) |
| **Build Tools** | Maven, npm |
